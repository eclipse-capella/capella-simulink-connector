# capella-simulink-connector
Connector for Capella and Simulink® software.

This connector bridges the gap between system architecture and simulation, making it possible to integrate Capella state machines and functional chains with Simulink® for simulation.

Thanks to this add-on, engineers can check their assumptions with Simulink and make sure their architecture design matches simulation constraints. Simulation engineers can focus on higher-value tasks, with better confidence that simulation scenarios remain consistent with the system design.

Learn more: [Webinar](https://www.youtube.com/watch?v=PXnMfgEoTGM)
